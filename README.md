# FluffyTail Apps website

Everything in this folder is uploaded as-is to the GitHub repository **`fluffytailapps.github.io`**
(in the GitHub organization `fluffytailapps`), which GitHub Pages publishes at
**https://fluffytailapps.github.io**.

| File | Published at | Purpose |
|---|---|---|
| `index.html` | https://fluffytailapps.github.io/ | Developer start page (enter as "Website" in the Play Console) |
| `app-ads.txt` | https://fluffytailapps.github.io/app-ads.txt | IAB Tech Lab app-ads.txt: AdMob checks it at the domain root. One file covers all FluffyTail apps |
| `listfox/privacy-policy.html` | https://fluffytailapps.github.io/listfox/privacy-policy.html | ListFox privacy policy (Play Console + AdMob consent message) |
| `listfox/terms.html` | https://fluffytailapps.github.io/listfox/terms.html | ListFox terms of service (Play Console trader / terms field) |
| `images/` | https://fluffytailapps.github.io/images/… | Logo, favicon and three app screenshots used by the start page (upload the whole folder) |
| `.nojekyll` | – | Tells GitHub Pages to publish files unchanged |

The start page says "Coming soon to Google Play". When ListFox is public, replace that with a link to
`https://play.google.com/store/apps/details?id=com.fluffytailapps.listfox` (Google's official "Get it on Google Play"
badge may be used, following Google's badge guidelines).

If the organization name `fluffytailapps` is not available, the address changes accordingly
(e.g. `fluffytail-apps.github.io`): update the URLs in `store/listing-en.md` too.
